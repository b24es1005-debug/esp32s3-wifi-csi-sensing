# Image Placeholders

Add screenshots/media assets in this directory to complete the project showcase.

## Suggested Files

- `banner_placeholder.png` (README banner, 16:9 or wider)
- `dashboard_placeholder.png` (main dashboard UI)
- `heatmap_placeholder.png` (CSI visual representation)
- `activity_prediction_placeholder.png` (predicted activity view)

## Notes

- Keep image names stable to preserve README links.
- Prefer compressed PNG/JPEG assets for fast page loading.
- You can add animated GIFs for demo sections if needed.
